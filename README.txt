DHANISH ❤️ VISHNU — LUXURY ROMANTIC SURPRISE WEBSITE
==================================================

HOW TO RUN
1. Extract this ZIP completely.
2. Open the Dhanish_Vishnu_Website folder in VS Code.
3. Open index.html in a browser (or use Live Server).

PERSONALIZE THE LOGIN
- Open config.js.
- loverName is already set to Vishnu.
- Replace secretDOB with Vishnu's actual date of birth in DDMMYYYY format.
  Example: 5 March 2004 -> 05032004.

LOVE STORY START DATE
- January 2, 2025 at 1:48 AM.
- The live counter uses this exact local date and time.

CUSTOMIZE MUSIC
- Replace audio/love-song.mp3 with your preferred MP3, keeping the same filename.

DESIGN
- Luxury burgundy, champagne gold and warm cream theme.
- Responsive layout, subtle star texture, floating hearts and animated transitions.
- No photo gallery section.
- Includes the supplied love letter and First Meet, First Hand Touch, First Hug memories.

NOTES
- The login DOB is a placeholder; replace it before sharing the site.
- No first-kiss date or timer is included.
- Internet is only needed for externally hosted fonts.
